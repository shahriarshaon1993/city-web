GitHub Actions is used only for the snapshot renderer (19.3), deploy (20.1) and the off-site backup pull (NFR-BAK-01); none of them runs tests or lint. `.github/dependabot.yml` stays until the owner decides otherwise.
- **DEC-28 (2026-10-25, plan) — Starter kit = official Laravel 13 Vue starter kit** (Fortify, Wayfinder, Inertia v3, TypeScript, shadcn-vue/reka-ui, Vite+ `vp`). - **DEC-32 (2026-10-25, plan) — Action Pattern for all application logic (owner's requirement).** Every write or business operation (create/update/publish/schedule/archive, submit lead, assign, change status, import, export, convert media, generate sitemap, request snapshot…) is one `final` class `app/Actions/{Domain}/{VerbNoun}.php` (e.g. `Projects/PublishProject`, `Leads/SubmitLead`, `Media/GenerateConversions`). Each has a single public `handle()` with typed parameters and return, dependencies injected through the constructor, resolved from the container; it owns its transaction and activity-log entry. No package (plain classes, like the Fortify actions). Controllers (ARC-001), jobs, listeners, console commands, schedulers and Fortify callbacks only orchestrate: authorise → validate (Form Request) → call an Action → respond. Actions call other Actions, never controllers. Read side stays as the spec says: Query classes (`app/Queries`, list/search reads), API Resources (prop shaping) and `app/Services` (SEO, SSR, block data loaders). Affects: every card from 0.3 on; overrides ARC-001's "Action/Query" wording only by making Actions mandatory.

- **DEC-36 (2026-10-25, 0.2) — Token additions and control states beyond §13.** Added `--primary-hover`/`--brand-accent-hover` (light teal-700/coral-700 per CMP-BTN-01; dark teal-200/coral-300), Tailwind colours for the success/warning/error/info scale steps used by badges, containers in `@theme static` (`max-w-content|wide|narrow`). - **DEC-37 (2026-10-25, 0.3) — Number/date formatting conventions.** Compact BDT uses `৳` per ARC-017 (`৳ 1.45 crore`), superseding the glossary's `Tk 1.25 crore`. A non-breaking space follows `৳` and precedes units. Compact: < 1 lakh full form, 2 decimals max, trailing zeros trimmed, 99,99,999 → `৳ 1 crore`. Ranges: `1,650–2,100 sft`, `৳ 85–95 lakh` (same unit), `৳ 85 lakh – 1.45 crore` (mixed). Grouping is hand-written in both twins (no Intl/`intl` ext) so PHP, SSR and browsers agree. Why: spec silent beyond the examples; no wrapped `৳`/units.

- **DEC-39 (2026-10-25, 0.4) — Head defaults where the spec is silent.** Canonical is omitted only on pages that are noindex by their own setting; the non-production / "noindex whole site" override (SEO-TEC-010) changes only `robots`, so local head output matches production.
